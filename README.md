# Lists for Homey

Lists, called Listri in the source code, brings shopping lists, tasks and notes to the Homey dashboard. Lists are Homey devices, so you can manage their contents from a widget and automate changes through Flows.

## Working with lists

Create multiple lists with their own icons and colors. Grocery items support quantities and categories; tasks support due dates and person assignments. Mark items complete, add notes and manage entries from the dashboard widget.

Flows can add, remove, check and uncheck entries. Triggers report changes and overdue tasks, while conditions check whether entries exist or are complete. Action cards can also return a list as plain text or Markdown for use in a message.

## Requirements

The app runs on local Homey version 12.4 or newer. Add a grocery list or general list as a device, then select it in a dashboard widget or Flow card.

## Source layout

- `drivers/` defines grocery list and general list devices.
- `src/list/` contains list behavior and `src/flow/` exposes it to Flows.
- `src/api/` contains API handlers.
- `ui-src/` contains the Vue interface, which builds into `assets/build/`.
- `widgets/` contains the dashboard widget integration.

The checked-in UI assets let you work on drivers and Flows without rebuilding the interface. Building the UI requires Font Awesome Pro access. Set `FONTAWESOME_NPM_AUTH_TOKEN` in your environment before installing the UI dependencies.

## Development

Use Bun for dependencies and scripts. Run these commands from the repository root:

```sh
bun install
bun run build
bun install --cwd ui-src --frozen-lockfile
bun run --cwd ui-src build
```

Edit Homey metadata in `.homeycompose/` and driver compose files where present. The root `app.json` is generated by Homey. `README.txt` and its translations contain the Homey App Store description; this Markdown file documents the GitHub project.
